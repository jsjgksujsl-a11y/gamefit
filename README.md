# GameFit 0.4 — каталог из 100 игр и профиль игрока

GameFit — русскоязычное веб-приложение для предварительного сравнения ПК с опубликованными системными требованиями.

## Возможности
- Каталог из 100 игр, поиск, категории и избранное.
- Для 16 исходных карточек сохранены добавленные ранее требования и ссылки на источники.
- Ещё 84 карточки добавлены. Их системные требования помечены как непроверенные: GameFit не придумывает характеристики и не выдаёт ложную проверку совместимости.
- Профиль ПК, тема и избранное сохраняются локально.
- Необязательные аккаунты Supabase: регистрация, вход, выход и облачная синхронизация профиля, избранного и темы.
- Без настройки Supabase сайт продолжает работать в локальном режиме.
- Проверка не обещает FPS и не гарантирует запуск.

## Включение аккаунтов
1. Создай проект Supabase.
2. В SQL Editor выполни содержимое `supabase-schema.sql`.
3. В Authentication настрой подтверждение почты и укажи адрес сайта в Site URL и Redirect URLs.
4. В `supabase-config.js` замени `YOUR_PROJECT` и `YOUR_SUPABASE_ANON_KEY` значениями Project URL и публичного anon/publishable key.
5. Опубликуй ветку с этими файлами. Регистрация и вход включатся автоматически.

**Безопасность:** используй только публичный anon/publishable key в браузере. Не помещай `service_role` или secret key в JavaScript. Не отключай RLS. SQL ограничивает доступ к строке владельцем по `auth.uid()`.

## Запуск
Для service worker и аккаунтов используй HTTPS или localhost:
```bash
python -m http.server 8000
```
Открой http://localhost:8000.

## Системные требования
Для новых карточек требования будут добавляться после проверки первоисточников. Пока у игры `min: null`, автоматическая проверка показывает «данные не проверены». Не заменяй этот статус догадками.

## Основные файлы
- `app.js` — каталог, сравнение и синхронизация аккаунта.
- `supabase-config.js` — URL проекта и публичный ключ.
- `supabase-schema.sql` — таблица и политики RLS.
- `privacy.html` — сведения о локальном и облачном режиме.
