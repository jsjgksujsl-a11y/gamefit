Твои данные — под твоим контролем.

GameFit 0.5 работает локально без аккаунта. Профиль ПК, избранное и тема сохраняются в localStorage браузера.

Аккаунт и облачная синхронизация

После настройки Supabase можно зарегистрироваться по электронной почте и паролю. В облако отправляются только профиль ПК, избранные игры, тема и идентификатор пользователя. Пароль обрабатывается Supabase Auth и не хранится в GameFit.

Таблица облачных данных защищена Row Level Security (RLS): пользователь может читать и изменять только собственную запись. SQL находится в supabase-schema.sql. Не отключай RLS.

Настройка

Для включения облака владелец проекта заполняет supabase-config.js URL проекта и публичным anon/publishable key, затем выполняет SQL-схему. Никогда не помещай service_role или secret key в браузерный код.

Автоматическое определение ПК

Браузер может сообщить приблизительный объём памяти, число логических потоков и имя графического адаптера. Эти значения могут быть неточными; точная модель оборудования не гарантируется.

Внешние сервисы

При включённом аккаунте применяются условия и политика конфиденциальности Supabase. Обложки и ссылки на магазины могут загружаться с внешних сайтов.

Удаление данных

Локальные данные можно удалить через настройки браузера. Облачные данные удаляются владельцем проекта из таблицы Supabase; удаление аккаунта Auth выполняется отдельно.
